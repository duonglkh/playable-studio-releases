# Playable Studio — Bản cài

Tải bản mới nhất ở mục **[Releases »](../../releases/latest)**:

| Hệ điều hành | File |
|---|---|
| **Windows 10/11 (x64)** | `PlayableStudio-Setup.exe` (trình cài) hoặc bản portable `.zip` |
| **macOS (Apple Silicon)** | `PlayableStudio.dmg` — mở rồi kéo app vào Applications |

> Công cụ desktop giúp team UA dựng **playable ad HTML5** từ brief (lái Claude/Codex CLI chạy ngầm).
> Lần đầu mở: nếu máy thiếu CLI, app có **nút cài sẵn**; sau đó **đăng nhập** Claude.ai (Pro/Max) hoặc ChatGPT (Plus, cho Codex).

### Lưu ý mở lần đầu (app chưa ký số)
- **Windows**: SmartScreen báo *"Unknown publisher"* → **More info → Run anyway**.
- **macOS**: Gatekeeper chặn → **chuột phải vào app → Open → Open** (hoặc *System Settings → Privacy & Security → Open Anyway*).

Mã nguồn nằm ở repo riêng tư.
